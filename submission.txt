Project Description:
Deepfake detectors reach 99 percent on clean test sets but their behavior under real world conditions is poorly understood. This project fine tunes ResNet 18 and EfficientNet B0 on the 140k Real and Fake Faces dataset, stress tests them with four image degradations (JPEG, noise, blur, downscaling) and four adversarial attacks (FGSM, PGD, Carlini and Wagner, EOT PGD), and evaluates three defenses (adversarial training, AFSL, and an ensemble). It also measures cross architecture black box transferability, runs frequency domain analysis on real vs fake images, and uses Grad CAM to visualize model attention before and after attack.

How to run (in order):
  pip install -r requirements.txt              install dependencies
  python3 train_baseline.py                    Train baseline ResNet 18
  python3 train_efficientnet.py                Train EfficientNet B0 baseline
  python3 run_attacks.py                       Run all attacks on baseline
  python3 train_robust.py                      Train with adversarial training
  python3 run_attacks_robust.py                Run attacks on robust model
  python3 train_afsl.py                        Train with AFSL defense
  python3 run_attacks_afsl.py                  Run attacks on AFSL model
  python3 run_transferability.py               Cross architecture transfer tests
  python3 run_ensemble.py                      Evaluate ensemble defense
  python3 run_advanced_attacks.py              Fine eps + C&W + EOT PGD
  python3 run_frequency_analysis.py            FFT of real vs fake
  python3 run_gradcam.py                       Grad CAM heatmaps
  python3 run_plots.py                         Generate all plots from JSON
  python3 generate_diagrams.py                 Pipeline and architecture diagrams
  python3 generate_report_images.py            Extra figures for the report

Key results:
  ResNet 18 baseline: 99.56 percent clean accuracy
  EfficientNet B0 baseline: 99.88 percent clean accuracy
  Under PGD eps=0.01: ResNet drops to 8.5 percent
  After adversarial training: recovers to 46.6 percent, only 0.6 percent clean accuracy lost
  Black box transfer at eps=0.01: target model holds around 60 to 70 percent

See report/report.pdf for full experimental results, discussion, and limitations.
